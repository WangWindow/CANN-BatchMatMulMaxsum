# Phase 1 Data Model（更新版）: 性能差距诊断与改进框架

**Feature**: 002-perf-gap-analysis | **Date**: 2026-10-14（第二轮更新）


本特性无外部数据存储；"数据模型" = 诊断/框架/实验的结构化实体与度量口径。

## Entities

### 测试点族 (Test-Point Family)
- 字段：族名、包含点、形状特征、现状用时、榜首用时、比值、差距性质
- **实例（27.21 判题）**：
  - 微型 P1–P4：8.18/8.97/7.00/9.38µs（**5.8~6.8×**，固定开销主导）
  - 小型 P5–P7：7.04/12.11/8.92µs（1.4~1.9×）
  - 中型 P13–P15：22.33/30.91/54.48µs（2.8/**3.7×**/6.7×；P14 已由触发解耦收敛）
  - 大型 P8–P12：110.9/199.5/175.5/223.1/188.6µs（2.3~6.4×）

### 根因项 (Root Cause)
- 字段：编号、机制、可观测证据、量级估计、分类、置信度
- **当前四项（Q3 更新）**：
  - **A 计算单元空转** [仍成立]：斜率 0.1µs/K ≈ 84 TFLOPS ≈ 峰值 21%（K 扫描）
  - **B C 数据 GM 往返** [**降级为非瓶颈**]：判别实验（C 翻倍 K 减半反而更快）
  - **C N 轴触发缺失** [**已交付**]：S12f 27.21，P14 ≥2×
  - **D 固定开销** [成立]：截距 ~99µs（C 往返 ~33µs + 每 tile/块 ~66µs）

### 改进方向 (Improvement Direction) → 行动项 (Action Item)
- 字段：编号、机制假设、预期收益、置信度、成本、风险、验证方法、回退点、判题可验证性
- **当前状态**：① 已交付；② → A2(fullload)+A5(环瘦身)；③ 降级（保留 A5）；④ → 探针先行；
  新增 A3(streamK/K 轴)、A4(swat/B 复用)；详见 plan.md「第二批次行动项」

### 实验资产 (Experiment Asset) [新增实体]
- 字段：名称、用途、文件路径、金标来源
- 实例：kscan_cases（K 域斜率归因）、tx_cases（装载路径对比）、disc_cases（C 通路判别）、
  nsd_cases/ns_cases/t_cases/s12_pts（触发面）、seq15/matrix_all（全量回归）、
  `BMMS_CORE_OVERRIDE`（核数变体 1/4/20/32）、soak_ts.py（触发路径稳定性）

### 判题轮次记录 (Judge Round) [新增实体]
- 字段：轮次、kernel md5、commit、总分、逐点用时、核心结论、后续动作
- 实例（近期）：S9=25.70(47dc041) → S12f=27.21(baa7ec7, P14 收) → S13a1=27.21(aed32b9, 同分, 噪声判定)

## Relationships

```text
测试点族 ──归因──> 根因项（多对多）
根因项 ──支撑──> 改进方向（多对一/多对多）
改进方向 ──排序──> 行动项（每批次可并行规划、串行实施）
行动项 ──执行──> 实验资产（对照）+ 判题轮次记录（验证）
```

## Validation Rules（口径约束）

| 规则 | 说明 |
|---|---|
| 判题为唯一真值 | 任何结论与判题冲突时以判题为准（FR-007） |
| 本地仅作 A/B | 本地为宿主口径，只用于"不劣化"筛查与相对对照 |
| 三口径交叉 | 每个根因须有判题数据 + 本地指标 + 手算流量/利用率中的 ≥2 项证据 |
| 噪声纪律 | 判题单次噪声 ±5%；单点 <15-20% 的改动不得单独判题归因；须捆绑提交 |
| 已否证不复验 | 清单见 research.md R6（含 B 侧装载重组等新增项） |
| 互斥声明 | fullload 与 streamK 互斥（同一形状二选一，按 K 分界） |
