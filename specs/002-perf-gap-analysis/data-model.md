# Phase 1 Data Model: 性能差距诊断与改进框架

**Feature**: 002-perf-gap-analysis | **Date**: 2026-10-14

本特性无外部数据存储；"数据模型"= 诊断/框架的结构化实体与度量口径。

## Entities

### 测试点族 (Test-Point Family)
- 字段：族名、包含点、形状特征、现状用时、榜首用时、比值、差距性质（结构性/参数性/固定开销）
- 实例（S11 判题）：微型 P1–P2（7.0/6.1×）；小型 P3–P7（1.5–3.9×）；中型 P13–P15（2.8/10.7/6.7×）；大型 P8–P12（2.8–9.3×）

### 根因项 (Root Cause)
- 字段：编号、机制、可观测证据、量级估计、分类（结构性/参数性/固定开销）、结论置信度
- 当前四项：A 计算单元空转（TFLOPS 证据）；B C 数据 GM 往返（流量公式）；C N 轴触发缺失（S11 判题不变证据）；D 固定开销（微型点绝对差）

### 改进方向 (Improvement Direction)
- 字段：编号、机制假设、预期收益、置信度、成本、风险、验证方法、回退点、判题可验证性
- 排序键：收益 × 置信度 ÷ 成本风险
- 当前四条：① 触发解耦；② Cube 喂数加深；③ C 通路改造；④ 微型点融合；附"已否证清单"

### 行动项 (Action Item)
- 字段：所属方向、变更范围、本地对照用例、通过判据、状态
- 首个：触发解耦 + 代价门槛标定（对照 = ns1/ns2/ns3 + c01–c05）

## Relationships

```text
测试点族 ──归因──> 根因项（多对多）
根因项 ──支撑──> 改进方向（多对一/多对多）
改进方向 ──排序──> 行动项（每次一个）
```

## Validation Rules（口径约束）

| 规则 | 说明 |
|---|---|
| 判题为唯一真值 | 任何结论与判题冲突时以判题为准（FR-007） |
| 本地仅作 A/B | 本地为宿主口径，只用于"不劣化"筛查与相对对照 |
| 三口径交叉 | 每个根因须有判题数据 + 本地指标 + 手算流量/利用率中的 ≥2 项证据 |
| 已否证不复验 | K 预重排、L1 半区 2→4 等进入"不再投入清单" |
