# Phase 0 Research: 性能差距诊断与改进框架

**Feature**: 002-perf-gap-analysis | **Date**: 2026-10-14

## R1 — 根因量化口径（如何把 5~10× 拆成可归因项）

- **Decision**: 采用三口径交叉验证：
  1) 判题逐点用时（设备侧）按形状族聚合，得每族比值；
  2) 本地 TFLOPS = 2×B×M×N×K / 设备耗时 → 与峰值对比得"计算单元利用率"；
  3) 结构流量估算：C 往返 = B×M×N×4B 写 + 同量读；输入 = B×K×(M+N)×2B。
- **Rationale**: 判题是唯一真值但无分解；本地可测指标能提供量级而非绝对值；流量/利用率可手算校验。
- **Alternatives considered**: 直接 specc profiling（判题不可得）；纯本地计时（宿主口径失真，S5b 已证）。

## R2 — 差距归因结论（首版）

- **Decision**: 四类根因，量级如下：
  - **A. 计算单元空转（最大杠杆）**：8192³ 实测 ~53 TFLOPS ≈ 峰值 15–25% ⇒ 喂数链（GM→L1→L0→mmad→搬出）串行；
  - **B. C 数据 GM 往返（结构性）**：每输出元素 4B 写 + 4B 读；8192² 量级 ≈ 0.5GB 纯开销流量；
  - **C. N 轴并行触发缺失**：P14/P15（10.7×/6.7×）的 workItems<核数且 est<12µs ⇒ 现有切分从未触发；
  - **D. 固定开销（微型点 7×）**：启动+握手+每格同步链 ~5–8µs，对 1–2µs 级成绩即全部差距。
- **Rationale**: 与判题逐点模式一致（微型点比值高且绝对差小；大点比值随 C 流量增大；P14/15 与 P13 的差异正对应触发与否）。
- **Alternatives considered**: 单一"框架慢"结论（无操作性，拒绝）。

## R3 — 首项行动：tileSplit 触发解耦（决策）

- **Decision**: 触发改为结构性资格：`tileEligible = (workItems < 核数) && (totalTilesAll ≥ 核数)`；
  再叠加**代价门槛**避免小点误触发；门槛用本地对照用例标定（ns1/ns2/ns3 + c01–c05 小点 A/B）。
- **Rationale**: S11 已证明机制正确（ns 3/3）但被 est 门卡死；est 门对该类形状低估 ≥7×，不可继续充当触发条件。
- **Alternatives considered**:
  - 修 est 公式（历史多次低估，样本不足）→ 保留为后续 ⑥ 类微调，不阻塞本行动；
  - 无条件全触发 → 小点（8µs 级）会被 memset/计数/多块调度吃掉，拒绝。

## R4 — 代价门槛的标定方法（决策）

- **Decision**: 以"误触发损失 ≤ 噪声"为约束：对小点族（P1–P7 类，本地 c00–c07）逐一比对
  触发/不触发的本地 A/B；门槛候选按 `totalTilesAll` 下限或 `nShards` 下限，取满足约束的最大胆值。
- **Rationale**: 判题为设备口径，本地墙只能做"不劣化"筛查；小点是当前最大比值族，不能为 P14/P15 牺牲它们。
- **Alternatives considered**: 以 est 作为二次门槛 → 已被 R3 否证其可信度，拒绝。

## R5 — 结构性方向（②③）的框架化（出方案不实施）

- **Decision**:
  - **方向②《Cube 喂数加深》**：候选机制 = L1 双缓冲加深与 K 块粒度、搬出与计算重叠加深、mmad 前段并行；
    验证口径 = 本地 TFLOPS（8192³/2048³ 等）提升幅度；
  - **方向③《C 通路改造》**：候选机制 = 更大环与批量搬出、归约消费端贴近生产端、减少 C 的 GM 读写轮次；
    验证口径 = 端到端吞吐 + 判题大点用时；此方向为与榜首结构差距的主嫌疑。
- **Rationale**: 两方向均可在一轮内以本地指标证伪/证实；先出机制清单与验证口径，待 S12 判题结果决定投入顺序。
- **Alternatives considered**: 立即实施方向③（成本高、缺少机制验证前置），拒绝。

## R6 — 微型点方向（④）与已否证清单

- **Decision**: 微型点融合（纯向量直算，砍跨核链）列为框架第 4 项（成本高、置信中），仅在 ①②③ 后仍有余力时投入；
  已否证方向（K 预重排、L1 半区 2→4 等）写入"不再投入清单"，除非有新证据。
- **Rationale**: 微型点总收益 ~+5–10 但改动面大；已否证方向重复尝试违反项目纪律。
- **Alternatives considered**: 无。
